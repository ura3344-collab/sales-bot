# Sales Bot — Telegram-бот інтернет-магазину

Бот приймає замовлення замість менеджера: показує каталог, збирає кошик, оформлює замовлення
і дає менеджеру панель керування просто в Telegram. Працює безкоштовно — без платних API та хостингу.

## Можливості

**Для клієнта**
- 🛍 Каталог за розділами (фартухи, фартухи з логотипом, кітелі, штани): картка моделі з фото, колір і розмір обираються кнопками, є розмірна сітка
- 🔥 Розділ «Хіти продажу» — список задається в `texts.py`
- 🔎 Пошук звичайним повідомленням: «Latte бежевий», «білий кітель Rio» — закінчення слів не важливі
- 🕓 Товари та розміри під замовлення: кнопка «Замовити через менеджера» надсилає менеджеру запит з посиланням на клієнта
- 🧺 Кошик: зміна кількості, підрахунок суми, підказка про безкоштовну доставку
- ✅ Оформлення замовлення покроково: ім'я → телефон (кнопкою або вручну, з перевіркою) → спосіб доставки (Нова Пошта, поштомат, Укрпошта) → адреса → оплата → коментар → підтвердження
- 🔁 Повторне замовлення: бот пропонує ті самі ім'я, телефон і адресу — одна кнопка замість трьох кроків
- 📦 «Мої замовлення» з поточним статусом і сповіщення, коли статус змінюється
- 👋 Нагадування про неоформлений кошик через 24 години
- ⭐ Оцінка замовлення від 1 до 5 після статусу «Виконано»
- 💬 Відповіді на питання звичайним текстом («скільки коштує худі?», «як працює доставка?»)

**Для менеджера**
- Миттєве сповіщення про нове замовлення з кнопками зміни статусу
- `/orders` — останні замовлення, `/stats` — виручка, середній чек, топ товарів, середня оцінка
- 📈 Щоденний звіт о 16:00 (час змінюється в `texts.py`) і `/report` — звіт за останню добу на вимогу
- 📄 `/export` — усі замовлення файлом Excel
- ⚠️ Повідомлення менеджеру про будь-яку помилку в боті з технічними подробицями
- Товари й ціни редагуються у `products.csv`, фото — у папці `photos/`, тексти — у `texts.py`; перезапуск не потрібен

## Технології

Python 3.13 · [python-telegram-bot](https://python-telegram-bot.org/) (asyncio) · SQLite · pytest · GitHub Actions · Render

## Структура

| Файл | Що всередині |
|---|---|
| `bot.py` | Обробники Telegram: меню, кошик, оформлення, панель менеджера |
| `shop.py` | Каталог, кошик, розпізнавання тем — чиста логіка без Telegram |
| `db.py` | Замовлення та налаштування в SQLite |
| `reports.py` | Щоденний звіт і вивантаження замовлень в Excel |
| `texts.py` | Усі тексти бота й ключові слова |
| `products.csv` | Товари: один рядок — один колір моделі. Наявність: `так`, `ні` або `під замовлення`; розміри через пробіл, `*` — під замовлення (`XS* S M L XL 2XL 3XL*`) |
| `photos/` | Фото товарів: файл називається за `id` рядка в `products.csv` — `1.jpg`, `3.png` (також `.jpeg`, `.webp`); розмірні сітки — у `photos/charts/` |
| `tests/` | Модульні тести та наскрізний сценарій із підміненим Telegram API |

## Запуск локально

1. Створіть бота в [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. Скопіюйте `.env.example` у `.env` і вставте токен.
3. Запустіть:

```
pip install -r requirements.txt
python bot.py
```

На Windows достатньо двічі клацнути `start.bat`.

4. Надішліть боту `/manager` з акаунта, який має отримувати замовлення.
5. *(Необов'язково)* Окрема група для замовлень: створіть групу в Telegram, додайте туди бота
   і надішліть у групі `/orderschat` з акаунта менеджера. Нові замовлення надходитимуть у групу,
   а статус можна змінювати кнопками прямо там. На хостингу збережіть показаний ID у змінній `ORDERS_CHAT_ID`.

## Віртуальний помічник «Анна»

Якщо задати змінну `ANTHROPIC_API_KEY` (ключ з [console.anthropic.com](https://console.anthropic.com)),
на будь-яке повідомлення клієнта одразу відповідає Анна — AI-помічник на Claude. Вона знає каталог
(ціни, кольори, розміри, наявність беруться з `products.csv`), умови доставки й контакти, пам'ятає
останні повідомлення розмови, а складні питання (знижки, опт, скарги) передає менеджеру.
Правила для Анни — у `texts.ASSISTANT_PROMPT`. Без ключа бот відповідає за ключовими словами, як раніше.

Кнопка «💬 Зв'язатися з менеджером» надсилає менеджеру запит разом з останніми повідомленнями клієнта.

## Логотип на одязі

Кнопка «🎨 Логотип на одязі» (або `/logo`): клієнт обирає виріб і надсилає логотип, а бот сам
прибирає фон, накладає логотип на фото в реальному масштабі й показує результат. Колір виробу, розмір
(7–25 см) і місце змінюються кнопками; темний логотип на темній тканині бот перефарбовує, щоб його було видно.
«✅ Замовити з логотипом» надсилає менеджеру візуалізацію та оригінал логотипа.

Де на кожному фото груди чи низ фартуха, задано у `logo_spots.csv`: `x`, `y` — частки ширини й висоти фото,
`ширина_кадру_см` — скільки сантиметрів уміщається в ширину фото (для фото в повний зріст ≈ 120).
Щоб додати виріб, допишіть рядки з його `id`; підписи місць і найбільший розмір — у `texts.LOGO_SPOTS`.

## Безкоштовний деплой (Render + GitHub)

1. На [render.com](https://render.com) увійдіть через GitHub → **New → Blueprint** → оберіть цей репозиторій
   (налаштування вже описані в `render.yaml`).
2. Вкажіть `TELEGRAM_BOT_TOKEN` і `MANAGER_ID` (свій ID підкаже [@userinfobot](https://t.me/userinfobot)).
3. Після деплою скопіюйте адресу сервісу (`https://….onrender.com`) у GitHub:
   **Settings → Secrets and variables → Actions → Variables → `BOT_URL`**.
   Workflow `keepalive` пінгуватиме сервіс, щоб він не засинав.

На хостингу бот сам перемикається з polling на webhook. Кожен `git push` запускає тести й оновлює бота.

> Диск безкоштовного тарифу Render не постійний: після перезапуску сервісу історія замовлень починається
> з нуля (менеджер зберігається, бо заданий через `MANAGER_ID`). Для демо цього достатньо; для реального
> магазину варто підключити зовнішню базу, наприклад безкоштовний PostgreSQL.
